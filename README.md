Overview

This project predicts stock closing prices using Machine Learning. Historical stock market data is used to train a Linear Regression model, which can estimate future stock prices based on input features such as Open Price, High Price, Low Price, and Volume.

Objective

The main goal of this project is to analyze historical stock data and build a prediction model that can estimate stock closing prices.

Technologies Used
Python
Pandas
Matplotlib
Scikit-learn
Dataset

The dataset contains historical stock market information including:

Open Price
High Price
Low Price
Close Price
Volume

Dataset Source: Kaggle

Project Workflow
Data Collection
Data Cleaning
Feature Selection
Train-Test Split
Model Training using Linear Regression
Model Evaluation using RMSE
Stock Price Prediction
Features
Data preprocessing
Stock trend analysis
Price prediction
Model evaluation
Visualization of results
Output

The model predicts the stock closing price based on user-provided stock parameters and displays prediction results along with performance evaluation metrics.

Conclusion

This project demonstrates how Machine Learning can be applied to financial data for stock price prediction. It provides a simple and effective introduction to predictive analytics in the stock market.
